Privacy Policy for Aura Leveling

Last updated: August 24, 2026

This policy covers what Aura Leveling accesses on your device and why. If cloud sync is enabled in a future release, this page will be updated to match before that release ships.

What this app is

Aura Leveling is a gamified fitness app: verified real-world workouts (camera-tracked pushups, voice-tracked “vocal surge” challenges, pedometer-tracked steps) power up a fighter character used in the app’s game modes.

Data this app accesses, and why

  • Camera: used locally to detect and count body movements during workout mini-games (e.g. pushup tracking). Camera frames are processed on-device for pose detection during these mini-games and are never saved or transmitted anywhere. A photo is only saved or sent elsewhere if you explicitly capture one for a specific feature — see “Bio-scanner and Meal Scanner (Google Gemini)” below for the one case where that happens.
  • Bio-scanner and Meal Scanner (Google Gemini): these two features let you photograph yourself (Bio-scanner) or a meal (Meal Scanner) to get an AI-generated rating or breakdown. To do this, the photo you capture is sent to Google’s Gemini API for analysis and is not processed on-device. This only happens if you’ve entered your own Google Gemini API key in the app (Settings) and then explicitly use one of these two features — the key and the resulting photo upload are both under your control, and the feature does nothing until you supply a key. Your Gemini API key is stored using your device’s secure keychain/keystore, never in plaintext. Use of the Gemini API for this analysis is subject to Google’s own privacy policy.
  • Microphone: used locally during the “Vocal Surge” mini-game to measure volume (decibels). Audio is not recorded to a file or transmitted anywhere — only the momentary volume level is read.
  • Activity Recognition / step sensors: used to count daily steps via the device pedometer, which feeds into the in-app fitness score.
  • Health Connect (steps, heart rate, active calories): if you connect a supported watch/band, the app reads these metrics from Android Health Connect to reflect real activity in your in-app power level. The app does not write data back to Health Connect.
  • Notifications: used for local reminders (e.g. daily streak alerts). These are scheduled on-device, not sent from a server.

What’s stored, and where

  • On-device: your profile (workout stats, in-app currency, equipped items, game progress) is stored entirely locally on your device. The app is fully usable offline, and as of this version, that’s the only way it stores data — no cloud sync is active yet.
  • Optional cloud sync (not yet enabled): a future version may add an opt-in cloud sync service (Firebase/Firestore) so your profile is available across devices and to support online features like rival trades/wagers and leaderboards. If and when that’s turned on, sign-in will be anonymous (no email/password required) unless an explicit account system is added, and this section will be updated to describe it before that release ships.
  • Photos: a profile picture you choose is stored locally only. A Bio-scanner or Meal Scanner photo is sent to Google’s Gemini API for analysis (see above) and is otherwise stored locally only; Aura Leveling itself does not keep a copy on any server.

What this app does NOT do

  • No advertising SDK and no ad tracking.
  • No analytics or crash-reporting SDK is currently integrated. (If one is added later — e.g. Firebase Crashlytics/Analytics — this section will be updated to disclose it before that release ships.)
  • Workout-tracking camera frames and microphone audio are never uploaded or shared with anyone; they’re processed on-device only. The one exception is the optional Bio-scanner / Meal Scanner features, which do send a photo you explicitly capture to Google’s Gemini API — see “Bio-scanner and Meal Scanner (Google Gemini)” above for details on when and why.

Your choices

  • Camera, microphone, activity, and notification permissions can be denied or revoked at any time in your device’s app settings; the relevant features simply won’t work without them, but the rest of the app still functions.
  • You can delete your local profile at any time from within the app’s profile management screen; since all data is stored on-device only (see above), this removes it completely. If cloud sync is enabled in a future version, this section will be updated to describe how cloud-synced data can be deleted as well.
